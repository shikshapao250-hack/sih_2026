# SkillBridge React Starter

## Run the project

Open the VS Code terminal in this folder and run:

```bash
npm install
npm run dev
```

Then open the local address displayed in the terminal (normally `http://localhost:5173`).

## First completed layer

- React + Vite setup
- Global styles
- Reusable `Button`, `Navbar`, and `Footer` components
- Home page with separate `Hero` and `RoleCard` components
- Separate `.jsx` and `.css` file for every component
- Student Dashboard with separate `SkillCard`, `OpportunityCard`, and `PortfolioCard` components
- Industry Dashboard with separate `JobCard` and `CandidateCard` components
- Academician Dashboard with a separate `FacultyOpportunityCard` component
- Separate Login and SignIn pages, with a reusable `RoleSelector` component

## Next layer

Connect the dashboards to real data and authentication when you are ready for the backend.
